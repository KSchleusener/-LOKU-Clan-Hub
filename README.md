# LOKU Pet Recorder 0.3 (Test)
Diese Version enthält verschiebbare, nummerierte Pet-Klickpunkte (originale Chibi-Maskottchen), den schwebenden Klicker sowie den Makro-Recorder zum Aufnehmen auf dem transparenten Trainingsfeld, lokalen Speichern, Abspielen und Teilen der Tipp- und Wischsequenzen. Roblox-Berührungen werden während einer Aufnahme nicht mitgelesen und nicht gleichzeitig ans Spiel durchgereicht.

**Dies ist eine eigenständige Test-APK, nicht die komplette große LOKU Clan Hub PLUS-App.**
Die komplette Clan Hub PLUS-Quelle enthält die entsprechende Pet-Marker-Implementierung und andere Clan-Module; hierfür ist noch ein eigener Android-Release-Build nötig.

App-ID `de.loku.eventclicker.petsrecorder2026`, debug signiert, Android SDK35. Für Updates muss später dieselbe Signatur verwendet werden.
